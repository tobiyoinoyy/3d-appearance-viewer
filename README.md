# 3D 看外观

在浏览器中查看手机、笔记本的 3D 外观，管理本地品类和 GLB 模型，手动导入图片预览不同 SKU。

## 功能

- 内置 iPhone 17 Pro、iPhone 17 Pro Max、MacBookTest 三台模型，完整保留模型自带贴图；MacBookTest 支持开合动画。
- 左侧模型库支持品类切换、搜索、新增和删除。删除入口集中在「管理」模式，操作需确认，文件移入本地回收站。
- 右侧按「贴图 / 灯光」分组；额外 SKU 图片需手动导入，仅用于当前预览，可以恢复原始贴图。
- 画布下方提供视角、网格和坐标轴工具；支持专注查看、窄窗口侧栏、沉浸演示、细节图片和窗口录制。
- 品类和模型目录写入本地文件夹，关闭浏览器和重启后保留。服务仅监听本机地址，不需要云端服务。

## 从 Git 下载后运行

安装 Node.js 22 或更新的兼容版本，然后执行：

```bash
git clone https://github.com/tobiyoinoyy/3d-appearance-viewer.git
cd 3d-appearance-viewer/程序
npm ci
npm test
npm run build
npm start
```

这是私有仓库，下载需要具有仓库访问权限。macOS 启动时会自动打开浏览器；其他系统可打开终端输出的本机网址。`npm stop` 停止后台服务。

首次安装依赖需要网络；构建完成后运行不需要联网。首次启动根据 `程序/src/spus.json` 建立 `数据/模型目录.json`，后续始终读取本地目录；清空目录不会自动恢复内置条目。

已交付到 Mac 的本地文件夹带有运行程序，可以继续双击「启动3D看外观.command」。Git 源码仓库不包含该平台的 Node 二进制文件或构建产物，从 Git 下载的副本请使用上面的安装与运行步骤。

## 开发

在 `程序/` 中执行 `npm start` 启动本地数据服务，再执行 `npm run dev` 启动开发页面。Vite 会将模型与目录请求转发到本地服务。修改后运行 `npm test` 和 `npm run build`。

## 文件结构与保存范围

| 位置 | 用途 |
| --- | --- |
| `程序/src/`、`程序/index.html` | 页面和 3D 查看器源码 |
| `程序/server.mjs`、`程序/catalog-store.mjs` | 本地服务、目录保存和回收站 |
| `程序/tools/` | 回归测试与模型检查工具 |
| `程序/public/` | 离线解码器、演示背景等资源 |
| `模型/` | 三台内置 GLB，以及在本地新增的模型 |
| `数据/` | 本地品类和模型目录、上次保存记录、回收站 |
| `docs/内置模型清单.json` | 内置模型大小与 SHA-256 校验值 |

Git 仅跟踪三台内置模型。运行日志、服务令牌、用户目录数据、回收站、后续新增的模型和本机检查备份均不提交。额外 SKU 图片只保存在浏览器内存中，不上传、不改写 GLB。更新内置模型时同步维护模型文件、种子清单及校验值；已有用户目录不会被种子覆盖。

完整操作说明见 [使用说明](使用说明.md)，实现说明见 [程序 README](程序/README.md)。Three.js 和随包运行程序的许可证分别位于 `程序/THREE-LICENSE.txt` 和 `程序/runtime/NODE-LICENSE.txt`。
